# Adaptive OFDM Receiver Selection

A MATLAB-based study of channel estimation techniques for Orthogonal Frequency Division Multiplexing (OFDM) systems, with an emphasis on estimation performance under noise and channel-model mismatch.

## Research objectives

- Establish and validate an OFDM simulation baseline.
- Evaluate bit error rate (BER) under additive white Gaussian noise (AWGN).
- Investigate cyclic-prefix effects in multipath channels.
- Compare least-squares (LS) and linear/PCHIP-interpolated channel estimates.
- Evaluate linear minimum mean-square error (LMMSE) channel estimation.
- Investigate sensitivity to channel covariance mismatch.
- Develop and evaluate a low-complexity adaptive estimator-selection strategy.

## Tools

- MATLAB R2025b
- Communications Toolbox
- Signal Processing Toolbox

## Current progress

Experiments 1–7 establish the simulation baseline and compare channel-estimation approaches. The adaptive receiver-selection algorithm remains a planned research component and requires implementation and validation.
